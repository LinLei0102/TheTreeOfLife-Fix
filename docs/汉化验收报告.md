## 中英切换

- 入口：设置面板第一行「语言 / Language: 中文」按钮
- 中文版在根目录，英文原版在 `en/`；共用存档键 `tree_of_life`
- 浏览器实测：中文版显示「生命点/成就/氢/升级/氘/花费/当前」，英文版逐字显示原版文本，切换正常

## 特殊处理

- 标签按钮：保留英文对象键作为存档键，通过 `ZH_TAB_LABELS` 在渲染层映射中文（`tools/zh/tab_labels.json`），避免旧存档失效
- 资源单位：`1 Animal reset` → `1 次动物重置`，`6 Animals` → `6 动物`，`log10(Organs)` → `log10(器官)`；公式里的 `replace()` 检索词同步汉化
- `taxonomySupport.js` 未被通用提取器覆盖，单独固化分类学长文案
- 系统组件补齐 `你有`、`离线时间：`、`需要 … 才能解锁`、`我是一个按钮！`
- 数字读法函数 `getNumberName*`（achievements.js）改造为中文数字（一/十/二十一/二百十一…），一次性覆盖所有数字词显示
- 大小写文字游戏 `INtestine/inTEStine/intesTINE`、`[方括号占位符]`、HTML 标签、数学函数名、科学计数均原样保留
- index.html 补 `<meta charset="utf-8">`（原版缺失，中文会乱码）
