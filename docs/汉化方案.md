## 路线判定

**选定路线：B（构建期/源码补丁）+ 位置性回填 + 双语切换层**

判据（按 route-selection 五问）：
0. 是否已有语言系统？**否**。无 i18n 目录/语言包；`vueFile.js` 是压缩的 Vue 运行时，`t()` 是其内部函数；`wordList.js` 是游戏机制的英文单词表；`layers.js` 的 `toLocaleUpperCase()` 只是字符串方法。→ 排除路线 I。
1. 文本是否同时是数据？部分是：层 id、升级编号、存档字段、`[占位符]`、HTML 标签、颜色值参与逻辑。→ 只能改展示文本，不能改这些 token。
2. 上游更新频率与构建链？上游活跃、无正式构建链。→ 位置性回填 + 词典独立存放便于跟版。
3. 关键文本是否在 DOM 之外？基本都在 DOM（Vue 模板 + 字符串方法返回），无 canvas 主要文本、无图片内文字。
4. 文本是否驱动排版/资源索引？否（英文节点名不参与查找，id 才是主键）。

文本形态：绝大多数在 `title()` / `description()` 方法内，通过 `return` 返回，夹带大量动态拼接（`"Estimated time: " + format(...)`）、HTML 标签、条件分支、`[占位符]`。因此采用**词法单元级翻译**：只翻含自然语言的字符串字面量片段，保留标签/变量/占位符/表达式原样。

规模：`layers.js` 约 26301 个字符串字面量，其中疑似展示文本约 1 万条；另有 `achievements.js`(~503)、`versions.js`(~566)、`components.js`(~97)、`index.html`(~108)、`mod.js`(~23) 等。`next/` 目录不被入口引用，排除。

## 明确不翻译清单

见 `docs/术语表.md` 第一节。核心：ID/键名/文件名/存档字段、`[...]` 占位符、HTML 标签、`br` 变量、颜色值、数学函数名、Decimal 大数后缀、动态拼接的表达式部分、 Johnson 等 targetWord 值。

## 实现结构

```
localization/zh/dictionary.json     # en -> zh 词典（分片合并，唯一译文来源）
tools/zh/extract.py                 # 词法扫描提取候选展示串，输出带位置信息
tools/zh/apply.py                   # 按位置从后往前回填，命中数断言，生成中文版源码
tools/zh/lang_layer.js              # 运行时语言层（localStorage 切换，默认中文）
docs/术语表.md
docs/汉化方案.md
save/endgame-*.json                 # 残局存档（收尾）
save/import.html                    # 免安装导入页（收尾）
```

回填策略：保留英文原版源码不动，生成一份中文版注入；通过语言层在设置面板提供中英切换（默认中文，英文模式逐字等于原版）。所有替换操作命中数必须等于预期，否则中止。
