# The Tree of Life 汉化术语表

本文件是唯一权威。所有分片翻译、批量替换都以它为准。译文并列用 `、`（不要用 `-`，避免被 id 掩码误伤）。

## 一、绝对保留原文（不译）

| 类别 | 内容 | 原因 |
|---|---|---|
| 语言/大数单位 | Life Points → 译为「生命点」；其余 Decimal 大数后缀、数学函数名（ln/log2/pow）保留 | 参与公式与解析 |
| 占位符 | `[best Hydrogen]`、`[Hydrogen upgrades]`、`[Achievements]` 等 `[...]` 内文本 | 运行时被替换，译掉会断引用；**整串保留原样**，如需可读可在词典里登记例外 |
| HTML 标签 | `<bdi>`、`<sup>`、`<sub>`、`br`（变量）、`<b>`、`<br>`、style 属性 | 结构符号 |
| 拼接变量 | `getUndulatingColor()`、`format(...)`、`makeBlue(...)`、`.replace(...)` | 代码 |
| 品牌/梗名 | The Tree of Life（游戏名，标题可译作「生命之树」但保持英文可识别）、Johnson（单词游戏里的 targetWord 值） | 专有名词 |
| 化学/科学符号 | H、H₂、eV、α、DNA、Hydrogen/Deuterium 等元素名采用通用中译，符号本身保留 | 科学术语 |
| ID / 键名 / 文件名 | 层 id（h/o/l/…）、升级编号、modFiles、存档字段、CSS 类名 | 逻辑主键 |
| 函数式标记 | `Estimated time: ` 后接动态值 → 译前缀「预计时间：」 | 保留动态拼接 |

## 三、标点与排版规范

- 译文用**全角冒号**：`（如）`、`预计时间：`；但紧跟变量拼接且原为 `: ` 时保持半角+空格以免破坏间距，具体由词典条目决定。
- HTML 标签、`<sup>`/`<sub>` 原样保留在译文中的相对位置。
- `<bdi>...</bdi>` 保留结构，只翻内部文字。
- `br`（变量，代表 `<br>`）不译、不动。
- 大数/格式函数输出不译。
- 「、」用于并列；数字、英文缩写与中文之间按中文习惯留半角空格（如 `100x` → `100 倍`）。
